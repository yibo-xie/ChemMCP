## Tool Details

### #341 GcColumnBleedPredictor (色谱柱流失温度限制提醒)
- **File**: `gc_column_bleed_predictor.py`
- **Function**: Predict GC column stationary phase bleed risk based on column type, temperature program, and detector
- **Features**: 30+ built-in stationary phase temperature limits, thermal stress calculation, detector-specific advice (MS/FID/ECD/NPD/FPD), gradient mode support, siloxane ion monitoring list
- **Test Results**: DB-5@280°C=moderate, DB-WAX@260°C=CRITICAL, gradient mode works correctly

### #342 IonChromatographyEluent (离子色谱淋洗液配制)
- **File**: `ion_chromatography_eluent.py`
- **Function**: Recommend and calculate IC eluent preparation recipes
- **Features**: 7 built-in recipes (carbonate/bicarbonate, hydroxide, MSA, nitric acid, borate, PHBA, auto-detect from analytes), exact mass/volume calculations, step-by-step preparation instructions, suppressor compatibility, analyte-specific notes
- **Test Results**: Anion auto-select → Carbonate/Bicarbonate ✓, Cation select → MSA ✓, Text mode ✓

### #343 SecCalibrationCurve (体积排阻色谱校正曲线拟合)
- **File**: `sec_calibration_curve.py`
- **Function**: Fit SEC/GPC calibration curve (log MW vs Ve) and predict unknown molecular weights
- **Features**: 5 built-in standard types (pullulan, PS, PEG, dextran, protein), linear regression with R², reduced plate height assessment, column separation range analysis, curve data generation (50 points), residual analysis
- **Test Results**: Pullulan data R²=0.9995, Built-in PS R²=1.0000, MW prediction accurate ✓

### #344 PeakPurityAnalyzer (峰纯度检验 DAD/MS确认)
- **File**: `peak_purity_analyzer.py`
- **Function**: Evaluate peak purity using DAD spectral similarity and MS confirmation
- **Features**: Spectral similarity index across peak (cosine-like), purity angle calculation, MS co-elution detection via multi-mass check, shape indicators (asymmetry, Gaussianity), composite scoring with configurable threshold, pass/fail verdict with diagnostic reasons
- **Test Results**: Clean peak PASS (score=0.999997) ✓, Impure peak FAIL ✓, MS clean detection ✓

### #345 SystemSuitabilityChecker (系统适用性测试参数计算)
- **File**: `system_suitability_checker.py`
- **Function**: Calculate and evaluate SST parameters against USP/pharmacopeial standards
- **Features**: Resolution Rs (baseline + half-height methods), tailing factor Tf, theoretical plates N, capacity factor k', selectivity α, repeatability RSD%, 3 standard sets (USP/general/strict), ASCII summary table, per-criterion pass/fail
- **Test Results**: Good system USP PASS (Rs=5.62, N=9700-11400) ✓, Poor system strict FAIL ✓, Text mode ✓

### #346 DeadVolumeCalculator (死体积和死时间计算)
- **File**: `dead_volume_calculator.py`
- **Function**: Calculate total system dead volume, component contributions, dead time, variance-based band broadening assessment
- **Features**: Component-by-component breakdown (tubing, detector cell, frits, guard column), cylindrical volume calculator, extra-column variance analysis (<10% rule), flow rate conversion, UHPLC narrow-bore warnings, optimization recommendations
- **Test Results**: Standard HPLC (4.6mm ID) ✓, UHPLC (2.1mm ID) high extra-column warning ✓, Text mode ✓

### #347 VanDeemterAnalyzer (Van Deemter 方程分析)
- **File**: `van_deemter_analyzer.py`
- **Function**: Fit Van Deemter equation H = A + B/u + C·u; determine optimal velocity and minimum plate height
- **Features**: Coefficient input or experimental data fitting (3×3 linear regression), optimal u/H/F calculation, Knox reduced parameters (h, ν, A/B/C_red), term breakdown at optimum (%A/%B/%C), Van Deemter curve generation (50 points), 3×3 matrix inversion solver, practical recommendations
- **Test Results**: Coefficient mode: u_opt=0.63mm/s, H_min=17.5μm ✓, Data fitting R²=0.986 ✓, Text mode ✓

### #348 CapacityFactorCalculator (容量因子 k' 计算)
- **File**: `capacity_factor_calculator.py`
- **Function**: Calculate retention factor k' and related parameters for method development
- **Features**: k' = (tR-t₀)/t₀, adjusted retention t'R, phase ratio β → distribution constant K, N estimation from Wh, k' range assessment (6 levels: invalid→optimal→too high), target range comparison, optimization action suggestions
- **Test Results**: Optimal k'=5.34 ✓, Low k'=0.34 warning ✓, High k'=23.39 warning ✓

### #349 SelectivityFactorCalculator (选择性因子 α 计算)
- **File**: `selectivity_factor_calculator.py`
- **Function**: Calculate selectivity factor α between peak pairs and predict resolution
- **Features**: α = k₂'/k₁', fundamental Rs equation, required N for baseline resolution, 6-level α assessment (co-elution→excellent), van't Hoff thermodynamic analysis (T effect on α), optimization strategy generator (thermodynamic vs kinetic approaches), critical pair identification
- **Test Results**: Well-separated peaks α_min=1.61, Rs_pred=8.46 ✓, Close peaks α_min=1.03 poor selectivity warning ✓

### #350 MolecularIonCalculator (分子离子峰质量计算 考虑加合物)
- **File**: `molecular_ion_calculator.py`
- **Function**: Calculate exact m/z values considering adducts, charge states, and isotope patterns
- **Features**: Molecular formula parser, monoisotopic mass calculation (40+ elements), 18 adduct types (ESI+/ESI-/EI), isotope pattern calculator (M through M+4, C-13/O-18/S-34/Cl-37/Br-81), nitrogen rule validation, degree of unsaturation (DBE), halogen pattern tips, MS identification guidance
- **Test Results**: C8H9NO2 MW=151.06 [M+H]⁺=152.07 ✓, Glucose Na adduct=203.05 ✓, Chlorobenzene Cl isotope M+2=32.68% ✓, Nitrogen rule satisfied ✓

## Development Notes

- All tools follow the ChemMCP BaseTool pattern with `@ChemMCPManager.register_tool` decorator
- Each tool supports both `code` (keyword arguments) and `text` (parsed string) interfaces
- No external API keys or services required — all pure computation
- Comprehensive metadata: version, description, I/O signatures, examples per tool
- Test coverage includes: normal cases, edge cases, text mode, error conditions
